## สิ่งที่ผมแนะนำให้ทำก่อน (ถ้าคอนเซ็บยังไม่ชัด)

เรียงตามอัตราส่วน "คุณค่า ÷ งาน":

1. **Agent loop หลายก้าว + ยืนยันก่อนทำ** — ทำให้ No7 ทำงานจริงได้ ไม่ใช่แค่ตอบ (1–2 วัน)
2. **สรุปความจำรายวันด้วย LLM + หน้าจอให้แก้/ลบ** — ความจำคือหัวใจของ "ผู้ช่วยส่วนตัว" (1–2 วัน)
3. **Wake word "No7" + ปุ่มลัดบนมือถือ** — เปลี่ยนจากการเปิดแอปเป็นการเรียกได้ทันที (2–3 วัน)
4. **MCP / ปฏิทิน / อีเมล** — ถ้าฉากหลักคือ "ผู้ช่วยทำงาน" (3–5 วัน)
5. **ต่อ ESP32 ผ่าน Phone-Link** — ถ้าฉากหลักคือ "ศูนย์ควบคุมอุปกรณ์" (ขึ้นกับฮาร์ดแวร์)
