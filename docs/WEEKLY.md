# 📆 รายงานรายสัปดาห์ (Weekly review)

มองย้อน 7 วันว่า "ทำอะไรไปแล้ว" และ "ควรโฟกัสอะไรต่อ" — ต่อยอดจากสรุปประจำวัน (`docs/DIGEST.md`)

## 1) ใช้งาน

| ทาง | ทำอะไร |
|---|---|
| ปุ่ม **📆 รายงานสัปดาห์** (หน้าตารางนัด) | การ์ดสรุป + โพสต์ในแชท |
| ถาม No7 ("สรุปสัปดาห์นี้ให้หน่อย") | AI เรียก tool `weekly` (risk 0 ไม่ต้องยืนยัน) |

## 2) กติกาเวลา

- สัปดาห์เริ่ม **วันจันทร์ 00:00** ตามเวลาเครื่อง (`weekStart: 1`; ตั้ง 0 = อาทิตย์)
- `weekRange(now)` → `{start, end, prevStart, prevEnd, label}` — `end` ไม่รวม (half-open)
- เทียบกับสัปดาห์ก่อนเพื่อบอก `deltaCompleted`

## 3) สิ่งที่นับ

| ตัวเลข | เกณฑ์ |
|---|---|
| `completed` | งาน `done` ที่ `updatedAt` อยู่ในสัปดาห์นี้ |
| `created` | งานที่ `createdAt` อยู่ในสัปดาห์นี้ |
| `overdue` | งานค้างที่ `due` เลยเวลามาแล้ว |
| `dueNextWeek` | งานค้างที่ครบกำหนดใน 7 วันถัดจากสิ้นสัปดาห์นี้ |
| `events` | นัดหมายที่ `start` อยู่ในสัปดาห์ |
| `newFacts` | ความจำที่ `ts` อยู่ในสัปดาห์ |
| `toolRuns` | metric ชนิด `tool` ในช่วง (แยกตามเครื่องมือ, มี `okRate`) |
| `chats` / `avgFirstTokenMs` / `failures` | จาก metrics ดิบ (`at`, `ok`, `firstTokenMs`) |

## 4) ข้อเสนอโฟกัส (ตามลำดับ)

| เงื่อนไข | ข้อความ |
|---|---|
| มีงานเกินกำหนด | `⏰ ปิดงานเกินกำหนด N อย่างก่อน` |
| ไม่ปิดงานเลยแต่มีงานใหม่ | `🎯 เลือกงานเล็ก ๆ สักหนึ่งอย่าง` |
| เพิ่มงาน > ปิดงาน | `📥 ลดรับงานใหม่ก่อน` |
| มีงานครบกำหนดสัปดาห์หน้า | `🗓 วางแผนล่วงหน้า` |
| ไม่มีความจำใหม่ | `🧠 สอนอะไรเกี่ยวกับตัวคุณสักอย่าง` |
| มีงานล้มเหลว | `⚠️ ตรวจการตั้งค่า` |
| ไม่มีอะไรต้องเตือน | `✨ สัปดาห์นี้ทำได้ดี` |

## 5) API

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `startOfWeek(ts, weekStart)` | ต้นสัปดาห์ของวันที่กำหนด |
| `weekRange(now, {weekStart})` | ช่วงสัปดาห์นี้ + ก่อน + label |
| `buildWeekly({tasks, events, facts, samples, now, weekStart, lang})` | ผลรวม + sections + focus + markdown |
| `weeklyMarkdown(weekly)` | ข้อความ markdown |
| `weeklyTool({tasks, calendar, memory, samples, lang})` | tool `weekly` (ดึงข้อมูลสดตอนเรียก) |

## 6) ข้อจำกัด

- งานที่ปิดไปแล้วแต่ไม่มี `updatedAt` จะไม่ถูกนับใน `completed`
- metrics เก็บแค่ 300 ตัวอย่างล่าสุด → สัปดาห์ที่ยุ่งมากตัวเลขเครื่องมืออาจต่ำกว่าจริง
- ยังไม่มีการส่งออกรายงานเป็น PDF/CSV และไม่มีการแจ้งเตือนอัตโนมัติ (มีแต่กด/ถาม)
- ใช้สัปดาห์เดียวต่อผู้ใช้ (ไม่มี timezone หลายเขต)
