# ⬇️ ส่งออกรายงาน (Markdown / CSV)

การ์ด **สรุปวันนี้** และ **รายงานสัปดาห์** มีปุ่มส่งออกสองแบบ
— ทำงานในเบราว์เซอร์ทั้งหมด ไม่มีการอัปโหลดข้อมูลออกไป

## ปุ่มบนการ์ด

| ปุ่ม | ไฟล์ที่ได้ | เหมาะกับ |
| --- | --- | --- |
| ⬇️ Markdown | `no7-digest-2026-11-10.md` / `no7-weekly-2026-11-10.md` | อ่านต่อ, วางใน Notion/Obsidian, ส่งในแชท |
| ⬇️ CSV | `no7-digest-2026-11-10.csv` / `no7-weekly-2026-11-10.csv` | เปิดใน Excel / Google Sheets / Numbers |

ชื่อไฟล์มีวันที่เสมอ (ไม่ทับกัน) และ CSV เริ่มด้วย **BOM** เพื่อให้ Excel อ่านภาษาไทยถูกต้อง

## รูปแบบ CSV

สามคอลัมน์คงที่: `หมวด, รายการ, รายละเอียด`

- รายงานสัปดาห์ขึ้นต้นด้วยบล็อก `สรุปตัวเลข` (งานเสร็จ/สร้างใหม่/เลยกำหนด/ครบกำหนดสัปดาห์หน้า/นัดหมาย/ความจำใหม่/เครื่องมือ/บทสนทนา/ข้อผิดพลาด)
  พร้อมค่าสัปดาห์ก่อนในวงเล็บเมื่อมี
- ตามด้วยรายการในแต่ละหัวข้อ (โฟกัสสัปดาห์หน้า, ปิดงานได้, งานค้าง, นัดหมาย, …)

การ escape: ค่าที่มี `,` `"` หรือขึ้นบรรทัดใหม่จะถูกครอบด้วย `"` และ `"` ซ้อนกลายเป็น `""`
ค่าที่ขึ้นต้นด้วย `=`, `+`, `-`, `@` จะถูกเติม `'` ข้างหน้าเพื่อกัน Excel ตีความเป็นสูตร

## รูปแบบ Markdown

```
# รายงานสัปดาห์ — 10–16 พ.ย. 2026
_2026-11-10_
**ปิด 3 · เพิ่ม 5 · ใช้เครื่องมือ 12 ครั้ง (+2)**

| ตัวชี้วัด | ค่า |
| --- | --- |
...
## 🎯 โฟกัสสัปดาห์หน้า
- ...
---
_No7 · สร้างเมื่อ 10/11/2026 09:12:33_
```

`reportMarkdown(report, { kind: 'weekly' | 'digest', lang: 'th' | 'en', now })`

## เมื่อเบราว์เซอร์ไม่รองรับการดาวน์โหลด

ถ้า `Blob`/`URL.createObjectURL` ใช้ไม่ได้ (เช่น in-app webview บางตัว)
ระบบจะคัดลอกเนื้อหาไปคลิปบอร์ดแทนและแจ้งในสถานะการตั้งค่า
(`📋 คัดลอก … ไปคลิปบอร์ดแล้ว`) — ข้อมูลไม่หายไปไหน

## API

| ฟังก์ชัน | คำอธิบาย |
| --- | --- |
| `escapeCsv(value)` | escape ค่าเดียว (quote + กันสูตร) |
| `toCsv(rows, { columns, header })` | ตาราง → CSV (CRLF) |
| `dateStamp(now)` / `datedFilename(base, ext, now)` | วันที่ `YYYY-MM-DD` + ชื่อไฟล์ |
| `weeklyCsv(weekly)` / `digestCsv(digest)` | CSV พร้อม BOM |
| `reportMarkdown(report, opts)` | Markdown (weekly/digest, th/en) |
| `downloadText(filename, text, { type })` | ดาวน์โหลด (คืน `false` เมื่อไม่รองรับ) |

ไฟล์: `web/src/core/report-export.js` · tests: `tests/report-export.test.js`

## ข้อจำกัด

- ไม่มี PDF และไม่มีการส่งออกอัตโนมัติตามเวลา (ต้องกดปุ่ม)
- CSV ครอบเฉพาะข้อมูลที่แสดงบนการ์ด (การ์ดตัดรายการที่เกิน 5–6 แถวต่อหัวข้อ)
- ตัวเลขเฉลี่ย `avgFirstTokenMs` แสดงใน Markdown เท่านั้น (ไม่ใส่ใน CSV)
- ไม่มี sheet หลายแท็บ/การจัดรูปแบบสี — ตั้งใจให้เป็นข้อมูลดิบ
