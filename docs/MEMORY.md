# ความจำ (Memory 2.0)

## เก็บอะไร อยู่ที่ไหน

ทุกอย่างอยู่ในเครื่อง (`localStorage['no7.memory.v2']`) เป็นเอกสารเดียว:

```js
{
  version: 2,
  facts: [{ id, text, tokens, importance(1-5), pinned, used, source, created, ts }],
  log:   [{ role, text, ts }],           // episodic log สูงสุด 800 ข้อความ
  meta:  { lastConsolidated, migratedFrom }
}
```

- **facts** = ข้อเท็จจริงระยะยาว (ตัดคำไทยเป็น bigram, strip tone mark)
- **log** = บทสนทนาดิบ ใช้เป็นวัตถุดิบของ consolidation
- เขียนทับจาก `no7.memory.facts.v1` / `no7.memory.log.v1` อัตโนมัติเมื่อเปิดครั้งแรก (migration)

## การค้นคืน (BM25)

```
score = BM25(k1=1.2, b=0.5) × importance × recency × pinBonus
recency    = 1 + 0.2·e^(−ageDays/30)
pinBonus   = 1.25
```

ทุกครั้งที่ค้นเจอ `used++` — ตัวเลขนี้ใช้สองที่: แสดง "ใช้ NN×" ในหน้าความจำ และเป็นเกณฑ์ตอน decay

## Consolidation (สรุปความจำ)

รันได้ 3 ทาง:
1. **อัตโนมัติ** — `startDailyConsolidation()` ตรวจทุก 6 ชม. และทำงานเมื่อ "มีบทสนทนาใหม่ ≥ 6 ครั้ง และผ่านมา ≥ 24 ชม."
2. **กดเอง** — หน้าความจำ → `🔄 สรุปความจำเดี๋ยวนี้`
3. **ตอนบูต** — ถ้าเข้าเงื่อนไข จะรันเบาๆ หลัง 4 วินาที

ขั้นตอน:
```
1. decay      ข้อเท็จจริงที่ไม่ได้ใช้ > 45 วัน → importance −1 (ไม่แตะ pinned)
2. heuristic  สกัดจาก log ใหม่ด้วย pattern ไทย/อังกฤษ (ฟรี ออฟไลน์ได้)
3. LLM        ถ้าเปิด "ใช้ AI ช่วยสรุปความจำ" → ขอ JSON array จากสมองที่ตั้งไว้
4. merge      รวมข้อเท็จจริงที่ซ้ำกัน (token overlap ≥ 0.7) เก็บข้อความที่สมบูรณ์กว่า
5. mark       บันทึก lastConsolidated
```

LLM ถูกจำกัด: สูงสุด 8 ข้อ, ข้ามข้อความชั่วคราว, และล้มเหลวเงียบๆ ได้ (heuristic ทำงานไปแล้ว)

## การจัดการของผู้ใช้

หน้า memory มี **ประวัติบทสนทนา** สำหรับอ่าน log ที่เก็บใน localStorage รวมถึงข้อมูลที่กู้คืนจาก backup ค้นหาข้อความและกรองผู้ใช้/No7 ได้ เรียงล่าสุดก่อน แสดงครั้งละ 50 และโหลดเพิ่มได้ครบถึงเพดาน log 800 ข้อความ หากแหล่งข้อมูลมีเกิน 800 จะแสดงคำอธิบายจำนวนที่ไม่แสดง การค้นหาเป็น local-only ไม่ส่งข้อความให้ AI/เครือข่าย; archive นี้อ่านอย่างเดียว ไม่มีปุ่มลบหรือแก้ไข

| ทำอะไร | ที่ไหน |
|---|---|
| เพิ่ม | ช่อง "สอนความจำใหม่" หรือพูด "จำไว้ว่า …" |
| แก้ | คลิกที่ข้อความ → แก้ inline → Enter |
| ปักหมุด | ปุ่ม 📍 (ไม่ถูก decay, ได้คะแนนค้นคืน +25%) |
| ลบ | ปุ่ม "ลบ" |
| ค้น | ช่องค้นหา (BM25) |
| กรอง | ทั้งหมด / ปักหมุด / ใช้บ่อย / ใหม่ |
| สำรอง | ⬇️ ส่งออก (JSON) · ⬆️ นำเข้า (merge หรือแทนที่) |

## ข้อจำกัดที่รู้ตัว

- pattern heuristic เป็น regex — ภาษาไทยไม่มีช่องว่างจึงจับได้เฉพาะรูปประโยคที่พบได้บ่อย
- decay ใช้ "ไม่ได้ถูกค้นคืน" เป็นสัญญาณว่าไม่สำคัญ ซึ่งอาจลดความสำคัญของเรื่องที่จริงจังแต่ไม่ค่อยถูกถาม (แก้ได้ด้วยการปักหมุด)
- ยังไม่มีการซิงก์ความจำข้ามเครื่อง (อยู่ในเฟส 4)
