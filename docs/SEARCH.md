# 🔎 ค้นหาทุกอย่าง (Command palette)

กด **⌘K / Ctrl+K** ที่ไหนก็ได้ → ค้นความจำ โน้ต รายการ งาน นัดหมาย เครื่องมือ เมนู และคำสั่ง
ในช่องเดียว แล้วกด Enter เพื่อไปทำต่อทันที

## 1) ใช้งาน

| ปุ่ม | ทำอะไร |
|---|---|
| `Ctrl/⌘ + K` | เปิด palette (ค้นจากข้อมูลสดทุกครั้ง) |
| `↑` / `↓` | เลื่อนผลลัพธ์ |
| `Enter` | เปิดผลลัพธ์ที่เลือก |
| `Esc` | ปิด palette (สำคัญกว่า modal อื่น) |
| คลิกพื้นหลัง | ปิด |

เปิดมาโดยไม่พิมพ์อะไร = ดูรายการล่าสุด/สำคัญ (เรียงตามชนิดข้อมูล)

## 2) การทำงานของผลลัพธ์

| ชนิด | เมื่อเลือก |
|---|---|
| 🧭 เมนู | เปลี่ยนหน้า (`showView`) |
| 🧠 ความจำ | ไปหน้าความจำ + ค้นคำนั้นให้เลย |
| 📝 โน้ต / ☑️ รายการ | ไปหน้าความจำ + แสดงข้อความในแถบสถานะ |
| ✅ งาน / 📅 นัดหมาย | ไปหน้าตารางนัด + แสดงหัวข้อ |
| 🧰 เครื่องมือ | ไปหน้าเครื่องมือ + แสดงคำอธิบาย |
| ⚡ คำสั่ง | `สรุปวันนี้` (เรียก digest), `หยุดทุกอย่าง` (stopAll), `เริ่มบทสนทนาใหม่` |

## 3) การให้คะแนน (`core/search.js`)

```
title == query            → 200
title ขึ้นต้นด้วย query    → 140
title มี query             → 110
text มี query              → 70
+ token ที่ตรง (title 18 / text 8)
+ ตรงทุก token              → 40
× น้ำหนักชนิด (ความจำ 1.1, งาน 1.05 … เมนู 0.8)
+ ความใหม่ (< 30 วัน), pinned, importance
- งานที่เสร็จแล้ว 12
```

- ตัดสินใจด้วย **ข้อความ** เป็นหลัก, ความใหม่เป็นเพียงโบนัสเล็ก ๆ
- จำกัด **ต่อชนิด** (`ceil(limit/3)` ขั้นต่ำ 2) กันผลลัพธ์ชนิดเดียวท่วม
- คำไทยใช้ bigram จาก `memory.tokenize` (ตัดวรรณยุกต์) → พิมพ์ "กาแฟ" เจอ "กาแฟดำ" ได้

## 4) API

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `buildIndex({memory, notes, todos, tasks, events, tools, views, actions})` | สร้างรายการค้นหา (ข้ามรายการที่ไม่มีข้อความ) |
| `searchIndex(index, query, {limit, types})` | ให้คะแนน + ตัดชนิด + เรียง |
| `groupResults(rows)` | จัดกลุ่มตามชนิด (เรียงตาม `TYPE_ORDER`) |
| `matchRanges` / `highlightRanges` | ตำแหน่ง highlight (แบบ normalize / แบบข้อความดิบ) |
| `defaultPaletteExtras()` | เมนู 7 หน้า + 3 คำสั่งมาตรฐาน |

- `buildIndex` รับข้อมูลดิบ (ISO string ก็ได้) — ไม่ผูกกับ storage
- UI สร้างดัชนีใหม่ทุกครั้งที่เปิด palette → เห็นข้อมูลล่าสุดเสมอ (ไม่มี stale cache)

## 5) ข้อจำกัด

- ค้นเฉพาะข้อมูลที่อยู่ในเครื่องนี้ (ไม่ค้นในแชทเก่าที่ไม่ได้บันทึกเป็นความจำ)
- ยังไม่มี fuzzy matching (พิมพ์ผิดหนึ่งตัวอาจไม่เจอ)
- highlight ทำงานกับข้อความที่ตรงกันแบบ substring เท่านั้น (ไม่ไฮไลต์รายคำเมื่อพิมพ์หลายคำ)
- ไม่มี typo correction / synonym
