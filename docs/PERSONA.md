# Persona Studio

## โครงสร้าง persona

```js
{
  id: 'p-lx3k-a1',          // built-in ใช้ id คงที่ (no7, jarvis, mira, …)
  name: 'น้องส้ม',
  emoji: '🍊',
  desc: 'ขี้เล่น พูดเก่ง',
  gender: 'female' | 'male' | 'neutral',   // → คำลงท้าย ค่ะ/ครับ
  system: 'คุณคือน้องส้ม ...',              // ตัวตน (system prompt)
  greeting: 'สวัสดีค่ะ …',                  // ข้อความแรกเมื่อเปิดแอป
  banned: ['การพนัน', 'การเมือง'],           // หัวข้อต้องห้าม
  style: { rate: 1.15, pitch: 1, voiceName: 'Kanya' },
  builtin: false,
  createdAt: 1760000000000,
}
```

เก็บที่ `localStorage['no7.personas.v1']` — **persona มาตรฐาน 8 ตัวแก้ไม่ได้** แต่ "ทำสำเนา" แล้วแก้ได้
ข้อความทุกช่องถูกจำกัดความยาว (ชื่อ 24, ตัวตน 1500, หัวข้อต้องห้าม 12 ข้อ) และ rate/pitch ถูก clamp ที่ 0.6–1.6

## การไหลเข้า prompt

```
persona.system
  + (banned.length ? "หัวข้อที่ต้องหลีกเลี่ยง…" : '')
  + กฎภาษา (ตอบไทย / คำลงท้าย)
  + บทบาท (mode)
  + สิทธิ์ (permission summary)
  + ความจำ BM25
  + รายการเครื่องมือ
```

`personaPrompt()` มีไว้สำหรับกรณีที่ต้องการเฉพาะก้อน persona (เช่นส่งให้ระบบอื่น)

## เสียง

`personaVoice(p)` ให้ `{rate, pitch, voiceName}` เป็นค่าเริ่มต้น
ลำดับความสำคัญ: ตั้งค่าเสียงของผู้ใช้ (`settings.voiceRate/Pitch/Name`) → ค่าใน persona → 1.0

## UI

หน้าตั้งค่า → 🎭 Persona Studio:
- การ์ดรายชื่อ (คลิก = ใช้ persona นั้นทันที)
- `＋ สร้าง persona ใหม่` / `ทำสำเนาตัวที่เลือก`
- ฟอร์ม: ชื่อ, อิโมจิ, คำอธิบาย, ตัวตน, คำทักทาย, หัวข้อต้องห้าม, คำลงท้าย, ความเร็วเสียง
- `🔊 ฟังเสียง` (พูดคำทักทายด้วยค่านี้), `บันทึก`, `ลบ`

## ข้อจำกัด

- ไม่มีการนำเข้า/ส่งออก persona เป็นไฟล์ (ใช้ Export ข้อมูลรวมในหน้าตั้งค่าแทน)
- persona ไม่สามารถบังคับ "ความสามารถ" ได้ — ทำได้แค่น้ำเสียง/หัวข้อห้าม (ความสามารถคุมด้วยโหมดและสิทธิ์)
