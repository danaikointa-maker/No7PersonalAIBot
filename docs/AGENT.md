# 🤖 Agent loop — หลายขั้น, เห็นทุกขั้น, หยุดได้

No7 ไม่ได้ตอบทีเดียวจบ แต่ "ทำงานเป็นขั้น" (สูงสุด `settings.maxSteps` ค่าเริ่มต้น 4)
แต่ละขั้นคือรอบคุยกับ AI 1 ครั้ง + เรียกเครื่องมือได้ 1 ตัว — และผู้ใช้เห็นทุกขั้นแบบสด ๆ

## 1) ลำดับเหตุการณ์ (events)

`core/agent.js` ส่ง event ผ่าน `onEvent` ทุกจังหวะ:

| event | ความหมาย | สิ่งที่ UI ทำ |
|---|---|---|
| `thinking` | เริ่มรอบที่ n (`step`, `maxSteps`) | แสดง "กำลังคิด · ขั้น 2/4" |
| `token` | คำตอบไหลมาทีละคำ | พิมพ์สด (streaming) + เริ่มพูดก่อนจบ |
| `tool` | กำลังเรียกเครื่องมือ (`tool`, `label`, `emoji`, `args`) | ขั้นใหม่สถานะ ⏳ |
| `result` | เครื่องมือคืนข้อมูล (`data`) | ขั้นนั้นเป็น ✅ + การ์ดผลลัพธ์ |
| `denied` | ถูกบล็อกสิทธิ์ หรือผู้ใช้กดไม่อนุญาต | ขั้นนั้นเป็น 🚫 |
| `error` | เครื่องมือ/AI ผิดพลาด | ขั้น ⚠️ พร้อมข้อความสั้น |
| `cancelled` | ผู้ใช้สั่งหยุด | ทุกขั้นที่ค้างอยู่เป็น ⏹ |

ผลลัพธ์ของ `agent.run()` = `{ text, trace, steps, blocked, cancelled }`
`trace` เก็บผลเครื่องมือทุกขั้น (ใช้สรุปปิดท้ายถ้าโมเดลไม่ยอมสรุป)

## 2) Timeline ที่ผู้ใช้เห็น

`core/timeline.js` แปลง event เป็น "ขั้นตอน" ที่ render ได้ (`#run-timeline` เหนือกล่องแชท):

```
⏳ กำลังคิด · ขั้น 1/4          →  ✅ กำลังคิด · ขั้น 1/4          (100 ms)
🌤 อากาศ                      →  ✅ 🌤 อากาศ — กรุงเทพฯ 32°C      (820 ms)
🚫 ผู้ใช้ไม่อนุญาต open_app
✅ เสร็จใน 3 ขั้น · 1.2s
```

- `AgentTimeline#push(event)` — ป้อน event (ผลลัพธ์รวมเข้าขั้นเครื่องมือ ไม่สร้างขั้นซ้ำ)
- `summary()` → `{ total, ok, error, denied, cancelled, ms, tools[] }`
- `headline()` → บรรทัดเดียว ("เสร็จใน 3 ขั้น · 1.2s" / "หยุดแล้วหลัง 2 ขั้น")
- `toRows()` / `toMarkdown()` → ข้อมูลสำหรับ render หรือคัดลอกเป็นรายงาน
- ไม่แตะ DOM และไม่เรียก AI → เทสต์ได้ด้วย `node --test`

## 2.1) การ์ดผลลัพธ์แบบ progressive

ผลของเครื่องมือแต่ละขั้น **ถูกวาดลงฟองคำตอบทันที** ที่ event `result` มาถึง ไม่ต้องรอคำตอบสุดท้าย:

```html
<div class="msg bot">
  <div class="msg-text">ราคาทองตอนนี้ 2,412 ดอลลาร์…</div>
  <div class="msg-cards" data-count="2">
    <!-- การ์ดของ gold, การ์ดของ calc (วาดตามลำดับที่เสร็จ) -->
  </div>
</div>
```

- ระหว่างยังไม่มีคำตอบ: `msg-text` แสดง `ได้ผลแล้ว — กำลังสรุป…` หรือ `เก็บผลแล้ว N อย่าง — กำลังสรุป…`
- token ที่ไหลมาหลังเครื่องมือเขียนลง `msg-text` เท่านั้น → ไม่ลบการ์ด
- `data-count` = จำนวนการ์ด (ใช้ตรวจในเทสต์/ตรวจสอบย้อนหลังได้)
- หนึ่งคำสั่งหลายเครื่องมือ = หลายการ์ดในฟองเดียว ตามลำดับที่เครื่องมือเสร็จ

## 3) หยุดกลางทาง

```js
agent.cancel('ผู้ใช้กดหยุด');   // ตั้งธง ไม่ตัดเน็ตทันที
```

ธงถูกตรวจ 3 จุดในลูป: ก่อนเริ่มรอบใหม่, หลังได้คำตอบจาก AI (ก่อนแกะ tool call),
และหลังกล่องยืนยัน — จึง **ไม่มีการเรียกเครื่องมือเพิ่ม** หลังสั่งหยุด

UI: ปุ่ม ⏹ ในแถบบน และแป้น `Esc` เรียก `stopAll()` ซึ่ง
1. `agent.cancel()` (ถ้ากำลังทำงาน) 2. `timeline.cancel()` 3. หยุดเสียงทันที

ผลลัพธ์เมื่อถูกยกเลิก: ข้อความสั้น ๆ + สิ่งที่ทำไปแล้ว (ถ้ามี) และ `cancelled: true`

## 4) ข้อจำกัด

- ระหว่างรอ AI ตอบ คำขอที่กำลังไหลอยู่หยุดได้เมื่อคำตอบมาถึง (ยังไม่ abort HTTP)
- `maxSteps` ยังเป็นค่ากลาง ไม่แยกตามโหมด (งานซับซ้อนอาจต้องการมากกว่า 4)
- timeline เก็บในหน่วยความจำของรอบนั้น — รีเฟรชแล้วหาย (ประวัติอยู่ในแชท)
