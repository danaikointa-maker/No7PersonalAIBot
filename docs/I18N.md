# 🌐 สองภาษา (ไทย / อังกฤษ)

No7 แยก **ภาษาของหน้าจอ** (`uiLang`) ออกจาก **ภาษาที่ AI ตอบ** (`language`) — เปลี่ยนหน้าจอเป็นอังกฤษ
ได้โดยไม่ทำให้ No7 พูดอังกฤษ

## 1) ใช้งาน

**⚙️ ตั้งค่า → ผู้ช่วย (Persona) → ภาษาของหน้าจอ → English**

- เปลี่ยนทันที ไม่ต้องรีโหลด
- บันทึกใน `localStorage['no7.settings.v1'].uiLang`
- `<html lang="...">` ถูกอัปเดตให้ screen reader/ตัวสะกดทำงานถูก

## 2) โครงสร้าง

```
web/src/core/i18n.js        ← พจนานุกรม + t() + applyI18n()
web/index.html              ← data-i18n / data-i18n-placeholder / data-i18n-title
web/src/main.js             ← applyUiLang() ตอนบูต + เมื่อเปลี่ยนภาษา
```

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `t(key, {lang, vars, fallback})` | แปลคีย์ + แทน `{var}` + fallback ไทย |
| `applyI18n(root, lang)` | ทับข้อความ/placeholder/title ตาม `data-i18n*` (คืนจำนวนที่แก้) |
| `langOf(value)` | ตรวจภาษา → ไม่รองรับคืน `th` |
| `detectLang(navLang)` | เดาภาษาจากเบราว์เซอร์ (`en*` → en) |
| `viewTitle(view, lang)` | หัวข้อหน้า (`view.*`) |

### ตัวอย่าง markup

```html
<button data-view="chat" data-i18n="nav.chat">💬 แชท</button>
<input id="input" data-i18n-placeholder="chat.placeholder" placeholder="พิมพ์หรือพูดกับ No7…" />
<button id="mic-btn" data-i18n-title="chat.mic" title="พูด (Push to talk)">🎤</button>
```

- ข้อความไทยอยู่ใน HTML ตรง ๆ → ถ้า JS ปิด/ยังโหลดไม่เสร็จ ยังอ่านได้
- `applyI18n()` ทำงานทั้งสองทิศ (en → th ได้) เพราะพจนานุกรมมีทั้งสองภาษา
- เทสต์บังคับว่าคีย์ `th` กับ `en` **ต้องมีครบเท่ากัน** และไม่มีค่าว่าง

## 3) เพิ่มภาษาใหม่

1. เพิ่มใน `LANGS` เช่น `ja: { label: '日本語', htmlLang: 'ja' }`
2. เพิ่ม `DICT.ja` ให้ครบทุกคีย์ (คัดลอกจาก `DICT.en` แล้วแปล)
3. เพิ่ม `<option value="ja">` ใน `#set-uilang`
4. `langOf()` จะยอมรับให้อัตโนมัติเมื่ออยู่ใน `LANGS`

## 4) ข้อจำกัด

- ตอนนี้แปลเฉพาะ **เปลือกแอป** (เมนู หัวข้อ ปุ่ม/placeholder/hint หลัก ~90 จุด) — ข้อความ runtime
  บางส่วน (สถานะเครื่องมือ, log, ข้อความในแชท) ยังเป็นไทย
- เนื้อหาที่ AI สร้างใช้ภาษา `language` ไม่เกี่ยวกับ `uiLang`
- ยังไม่รองรับ RTL (ขวา→ซ้าย)
